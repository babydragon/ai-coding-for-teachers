# 01 · 安装与模型配置

> 这一章带你完成两件事：
> 1. 在电脑上装好 Reasonix（桌面图形界面版，下文简称「桌面版」）。
> 2. 配好大模型（拿到 API Key 填进去），让它能真正开始干活。
>
> 全程不需要写代码，跟着做就行。

---

## 1. 准备工作：你需要什么

| 需要的东西 | 说明 |
| --- | --- |
| 一台电脑 | 普通 Windows 电脑就够（绝大多数老师都是 Windows 系统，本指南按 Windows 讲解） |
| 网络 | 安装时需要联网；注册大模型账号需要联网 |
| 一个邮箱 | 用来注册大模型厂商账号 |
| 一点点耐心 | 首次配置 15 分钟左右 |

## 2. 第一步：安装 Reasonix 桌面版

**Reasonix** 是「组织大模型干活的工具」。它的桌面版是一个带图形界面的应用，安装后桌面上会有图标，双击就能打开。

👉 动手做：

1. 打开 Reasonix 官方网站（或学校统一分发的安装包/网盘链接）。
2. 下载安装包：Windows 系统下载 `.exe` 安装包（如果拿不准自己该下哪个，直接问学校的信息技术老师或网管）。
3. 双击安装包，按提示「下一步 / 安装 / 完成」即可。
4. 安装完成后，桌面上会出现 Reasonix 图标。

⚠️ 注意：
- 如果学校有统一的信息技术老师或网管，可以请他们帮忙批量安装。
- 安装时如提示「是否允许访问文件」之类，选择允许（Reasonix 需要在你的项目文件夹里创建和修改文件）。

## 3. 第二步：认识「模型」——选一个大脑

Reasonix 本身**不含**大模型，它需要「接」一个大模型厂商的服务。就像打印机需要装墨盒，Reasonix 需要一个「模型」才有智能。

### 3.1 选哪家？（国内老师推荐）

| 厂商 | 特点 | 说明 |
| --- | --- | --- |
| **DeepSeek（深度求索）** | 性价比高、中文好、数学能力强 | 本指南示例用的就是 DeepSeek，适合做学生工具 |
| 智谱 GLM | 中文好、生态完整 | 可选 |
| 通义千问（阿里） | 中文好、有免费额度 | 可选 |
| Kimi（月之暗面） | 中文好、长文本强 | 可选 |
| GPT（OpenAI） | 通用能力强 | 国内访问需网络条件，按需选择 |

> 老师做学生工具，**DeepSeek 通常是性价比最高的选择**，本指南全部示例都用它。

### 3.2 拿到「门禁卡」：注册并获取 API Key

以 DeepSeek 为例：

👉 动手做：

1. 打开 DeepSeek 开放平台（`platform.deepseek.com`），用邮箱注册登录。
2. 进入「API Keys」页面，点「创建 API Key」。
3. 复制生成的 Key（一串字母数字），**先粘贴保存到记事本里**。
4. 充值一点金额（做学生小游戏，通常几块钱能用很久；也有一定免费额度，以平台当期政策为准）。

⚠️ 注意：
- **API Key 相当于密码**，不要发到群里、不要截图发给别人。
- Key 只在创建时完整显示一次，弄丢了就重新创建一个。
- 收费是按使用量（Token）计算的，日常做小工具用量很小，不用担心费用爆表；Reasonix 界面能看到每次的花费。

## 4. 第三步：把 Key 填进 Reasonix（配置模型）

👉 动手做（桌面版）：

1. 打开 Reasonix 桌面版。
2. 找到「设置 / Settings」（一般在右上角，齿轮图标）。
3. 进入「模型 / Model」→「服务商 / Providers」或「接入 / Access」页面。
4. 选择你的厂商（如 DeepSeek），粘贴刚才的 API Key。
5. 选择默认模型（如 DeepSeek 的 `deepseek-v4-flash`，性价比高；更复杂的任务可切 `deepseek-v4-pro`）。
6. 保存。此时界面底部状态栏会显示当前模型，说明配置成功。

> 💡 进阶（了解即可）：Reasonix 的配置其实是一个叫 `config.toml` 的文本文件，由软件自动管理，一般不用手动去找它、改它。桌面版「设置」界面改的就是这个文件，老师用图形界面就够了。

### 配置文件的秘密（了解即可）

如果你好奇，配置文件长这样（已隐去敏感信息）：

```toml
default_model = "deepseek/deepseek-v4-flash"   # 默认用哪个模型

[[providers]]
name        = "deepseek"                       # 服务商名字
kind        = "openai"                         # 协议类型
base_url    = "https://api.deepseek.com"       # 服务地址
api_key_env = "DEEPSEEK_API_KEY"               # Key 存在环境变量里，不写进文件
```

⚠️ 注意：**API Key 永远不要直接写在配置文件里**。Reasonix 把密钥存在独立的 `.env` 文件里（权限保护），配置里只写「去哪个环境变量取」。

## 5. 第四步：验证配置成功

👉 动手做：

1. 在 Reasonix 输入框里随便问一句，例如：**「你好，介绍一下你自己，用 50 个字。」**
2. 按回车（或点发送）。
3. 如果收到了回答 → 配置成功，可以开始干活了 🎉
4. 如果报错（如「401」「没有权限」「Key 无效」）→ 回到第 3 步检查 Key 是否粘贴完整、有没有多余空格。

## 6. 常见问题速查

| 问题 | 原因与解决 |
| --- | --- |
| 提示 API Key 无效 | Key 复制不全或已过期；重新创建并粘贴 |
| 提示余额不足 | 去厂商平台充值 |
| 回答很慢 | 网络原因或高峰期；可换个时间，或换更快的模型 |
| 想换一家厂商 | 设置里再加一个服务商，填新的 Key 即可；可以同时配多家 |
| 费用多少？ | Reasonix 状态栏实时显示每次对话的花费；做小工具单次任务通常几分钱到几毛钱 |
