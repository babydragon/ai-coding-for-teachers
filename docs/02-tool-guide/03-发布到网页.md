# 发布到网页的三种方式

> 想让老师们不用下载就能在线看这份指南？有三种方式，按「省事程度」从高到低排列。
> 全部**不需要花钱**，也不需要会写代码。

## 方式一：直接推到 GitHub 在线看（最省事，零配置）

GitHub 会自动渲染 `.md` 文件——把项目推上去，所有章节在网页上就能直接阅读，**章节之间的链接自动可点**（GitHub 原生支持 `./`、`../` 相对链接），中文文件名也没问题。

👉 动手做：

1. 在 [github.com](https://github.com) 注册账号（免费）。
2. 新建一个仓库（Repository），名字随意，比如 `ai-coding-for-teachers`。
3. 把项目文件夹里的内容全部上传（网页上点「Add file → Upload files」即可，不用命令行）。
4. 打开仓库主页，就能看到 README.md 渲染后的样子，点目录里的链接就能翻页。

优点：零配置、永久免费、改文件后刷新即生效。
缺点：样子比较朴素（就是 GitHub 的样式），没有漂亮的目录侧边栏。

## 方式二：GitHub Pages（免费，样式更好看）

GitHub Pages 可以把仓库发布成一个正式的网站，网址形如 `https://你的用户名.github.io/ai-coding-for-teachers/`。

做法（任选其一）：

**A. 直接放单文件 HTML（最简单）**
1. 在本项目目录运行：`./export.sh --html`
2. 得到 `dist/面向教师的AI编码指南.html`——这是一个**单文件网页版**，样式美观、打开即用。
3. 把 `dist/` 里的这个 HTML 传到仓库里。
4. 在仓库设置（Settings → Pages）里，把发布来源（Source）选成分支（Branch），保存。
5. 等一两分钟，访问生成的网址即可。

**B. 自动构建（每次推代码自动更新）**
让 GitHub 在每次推送时自动运行 `./export.sh --html` 并发布（需要 `.github/workflows/pages.yml` 工作流文件，可让 Reasonix 帮你写）。

## 方式三：Cloudflare Pages（免费，速度快）

Cloudflare Pages 功能和 GitHub Pages 类似，但网站托管在 Cloudflare 全球网络，国内访问通常更快。

做法：
1. 把项目推到 GitHub（同上）。
2. 在 [dash.cloudflare.com](https://dash.cloudflare.com) 注册账号（免费）。
3. 进入 **Workers & Pages → Create → Pages → Connect to Git**，选你的仓库。
4. 构建命令（Build command）填 `./export.sh --html`，输出目录（Output directory）填 `dist`。
5. 保存后自动构建，得到一个 `https://xxx.pages.dev` 的网址。

之后每次推代码，Cloudflare 都会自动重新生成并发布。

## 三种方式怎么选？

| 需求 | 推荐方式 |
| --- | --- |
| 只想让老师们**快速能看**，不折腾 | 方式一（GitHub 直接看） |
| 想要正式网址、好看一点 | 方式二（GitHub Pages，方案 A 即可） |
| 老师们国内访问多、想要快 | 方式三（Cloudflare Pages） |

> 💡 小提示：三种方式可以同时用，互不冲突。文档本身是 Markdown，随时可以重新导出、重新发布。
