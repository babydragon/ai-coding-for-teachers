# 03 · AGENTS.md 的安装与更新

> 这一章讲三件事：
> 1. 怎么把 AGENTS.md「装」好——先分清**全局校规**（管所有项目）和**项目班规**（只管本项目）；
> 2. 怎么验证装好了、生效了；
> 3. 以后想改规矩，怎么「更新」。

---

## 1. 安装：三步搞定

### 第 0 步（先想清楚）：这份规矩是「校规」还是「班规」？

动手前先问自己一句：**这些要求是所有学生工具都要遵守的，还是只有这个项目需要？**

| | 全局（校规） | 项目（班规） |
| --- | --- | --- |
| 放哪 | Reasonix 的全局数据文件夹（让 AI 帮你放，或桌面版设置里操作） | 项目文件夹根目录 |
| 生效范围 | 所有项目、所有会话 | 只有这个项目 |
| 适合放什么 | 「给学生做的工具必须离线、简体中文、不收集学生信息」这类**永远成立**的底线 | 「本游戏针对三年级竖式乘法、配色浅黄」这类**只属于本项目**的要求 |
| 常见问题 | 写多了会让所有项目都背着这份要求（费一点 Token） | 换一个项目就要重新装一份 |

判断口诀：**「别的项目也用得上」→ 校规；「只有这个项目才这样」→ 班规。**

> 💡 新手建议：先不急着装全局。**先做一份项目班规**，用顺手了、确认哪些要求「每个项目都用得上」之后，再把那部分提炼成全局校规。全局校规写多了，反而会让不相关的项目也背上无关要求。

### 第 1 步：准备文件

方法 A（推荐，用现成模板）：

**装「班规」（项目级）：**
1. 打开本指南的 [`templates/`](../../templates/) 文件夹。
2. 挑一个合适的模板（比如 [`AGENTS.md.学生工具-通用.md`](../../templates/AGENTS.md.学生工具-通用.md)）。
3. 把文件复制到你的项目文件夹根目录，**改名为 `AGENTS.md`**（注意：文件名一个字母都不能差，就叫 AGENTS.md，没有别的后缀）。

**装「校规」（全局级）：** 全局文件不需要自己找文件夹——最省事的是让 AI 放：

> 「帮我把『给学生做的工具必须：单个文件离线运行、全简体中文、不收集学生信息、配色明亮』存成全局 AGENTS.md。」

AI 会放到 Reasonix 的全局数据文件夹。之后**任何项目**的新会话都会自动读到这份校规。

方法 B（让 AI 帮你写）：

在 Reasonix 里对你的项目说：

> 「帮我在这个项目里创建一个 AGENTS.md，内容按《面向教师的 AI Coding 指南》第四部分的学生工具通用模板来，目标用户是三年级学生。」

AI 会分析项目并生成。生成后建议对照模板检查一遍。

> 💡 如果你完全不想动手：**也可以直接输入 `/init`**，Reasonix 的 init 技能会分析项目并自动生成一份基础的 AGENTS.md。之后再按本文第 3 节的方法补充你的要求。

### 第 2 步：确认位置

**项目「班规」**的文件结构应该是这样：

```
D:\学生工具\乘法小游戏\
├── AGENTS.md          ← 根目录，文件名精确为 AGENTS.md
├── index.html
└── ...
```

⚠️ 注意：
- **必须放在项目根目录**，不能放在子文件夹里（Reasonix 只认根目录的这个文件）。
- 文件名不要写成 `AGENTS.md.txt`、`agents.md`（大小写一般无所谓，但后缀不能有）。

**全局「校规」**不需要记文件夹位置：它由 Reasonix 自动管理，放在全局数据文件夹。想核对有没有装好，直接在第 3 步的验证里问 AI 即可。如果以后想在桌面上直接看/改，可以在 Reasonix 桌面版的设置里找「全局记忆 / Instructions」入口。

### 第 3 步：验证生效

👉 动手做：

1. 在 Reasonix 里**新开一个会话**（旧会话不重新读 AGENTS.md）。
2. 输入一句很「容易犯规矩」的话测试，例如：
   > 「简单说下你会怎么做这个项目。」
3. 观察 AI 的回答里有没有体现 AGENTS.md 的规矩（比如主动提到「单文件」「离线」「适合三年级」等关键词）。
4. 如果提到了 → 安装成功 🎉；没提到 → 检查文件名/位置，然后重开会话再试。

> 或者直接问它：「这个项目的 AGENTS.md 里写了哪些要求？」它能准确复述出来，就说明读进去了。
>
> 验证**全局校规**同理，但要在**另一个项目**里新开会话再问，例如「我们全校对学生工具的通用要求是什么？」——能复述，说明校规生效。

## 2. 快速自查清单

| 检查项 | 对不对 |
| --- | --- |
| 项目班规在项目根目录 | ☐ |
| 文件名是 `AGENTS.md`（无多余后缀） | ☐ |
| 全局校规由 AI 放进了全局数据文件夹 | ☐ |
| 内容是 Markdown 格式（`#` 开头的小节） | ☐ |
| 新开会话后 AI 能复述其中的要求 | ☐ |
| 没有把 API Key 等机密写进文件 | ☐ |

## 3. 更新：改规矩的两种方法

### 方法 A：自己直接改文件（推荐，最可控）

AGENTS.md 就是普通文本文件，用记事本/VSCode 打开就能改：

1. 打开项目根目录的 `AGENTS.md`。
2. 修改对应小节，例如把「目标用户是小学 3~4 年级」改成「目标用户是初一学生」。
3. 保存。
4. 在 Reasonix **新开会话**，新规矩生效。

> ⚠️ 已打开的会话不会自动重新读取，**改完必须新开会话**。

### 方法 B：让 AI 帮你改

在 Reasonix 里说：

> 「把 AGENTS.md 里配色那节改成校徽的蓝色系，具体色值 #1565C0，然后新开会话验证生效。」

AI 会帮你改文件。改完自己瞄一眼内容确认没改错。

### 更新之后一定要做的：回归测试

改了规矩后，重开一个会话，说一句测试话，确认 AI 按**新**规矩回答（同上文「验证生效」）。

> ⚠️ 全局校规改了，同样要**新开会话**才生效（旧会话不会重读）。改完在**任意项目**新开会话测试即可。

## 4. 常见问题

| 问题 | 解答 |
| --- | --- |
| 改了 AGENTS.md 但 AI 没反应 | 旧会话不会重读；关掉重开一个会话 |
| AI 说「没找到 AGENTS.md」 | 检查文件名是否有 `.txt` 后缀，或文件是不是放错文件夹了 |
| 可以放多个 AGENTS.md 吗？ | 一个项目只认根目录一个；不同项目各放各的。另有一份全局的管所有项目，两者不冲突 |
| 全局校规和项目班规打架怎么办？ | 先读校规再读班规、两份都算数；设计时尽量让班规只写本项目特有的要求，别和校规冲突 |
| 哪些要求该放校规？ | 任何项目都成立的底线（离线、中文、安全、不收集学生信息）；只属于本项目的放班规 |
| 全局文件我自己找得到吗？ | 不需要手动找：让 AI 存，或在桌面版设置里查看「全局记忆 / Instructions」 |
| AGENTS.md 会被别人看到吗？ | 项目文件就在项目文件夹里，项目拷给谁谁就能看到——里面别写密钥、别写学生隐私 |
| 会不会让 AI 变慢变贵？ | 会占用一点点上下文（每次会话都读），所以保持精炼，别写废话 |
| 我英语不好，能写中文吗？ | 能！AGENTS.md 用中文写完全没问题，AI 完全看得懂 |

## 5. 小结

- **两级规矩**：全局「校规」管所有项目（放在 Reasonix 全局数据文件夹，让 AI 存即可）；项目「班规」只管本项目（放在项目根目录、名为 `AGENTS.md`）。
- **安装** = 项目班规：模板文件放进项目根目录改名；全局校规：让 AI 存进全局数据文件夹。装完**新开会话**验证。
- **验证** = 新开会话，问 AI「这个项目的规矩是什么」（项目）或「全局对学生工具的要求是什么」（全局），能复述即生效。
- **更新** = 直接改文件（或让 AI 改），然后**新开会话**回归测试。
- 保持文件精炼，不写机密。
