# 02 · 学生工具通用要求与模板

> 这一章给你一份**可以直接抄的 AGENTS.md 通用模板**，并逐条解释每条规矩「为什么这么写」。
> 这份模板是给「老师制作给学生用的工具」的通用预设，覆盖技术栈、交互、配色、内容、安全等维度。
> 完整可复制版本见 [`templates/AGENTS.md.学生工具-通用.md`](../../templates/AGENTS.md.学生工具-通用.md)。

---

## 1. 通用模板全文（先抄这个）

> 使用方法：新建一个项目文件夹，把这个文件保存为项目根目录的 `AGENTS.md`，
> 然后就可以用一句话让 AI 干活了（怎么装、怎么更新见《03 · 安装与更新》）。

```markdown
# 学生工具项目

这是老师为学生制作的互动学习工具项目。
目标用户是【小学 3~4 年级】学生，所有设计都必须围绕「孩子看得懂、玩得动、学得进」。

## 技术栈（必须遵守）
- 做成单个 HTML 文件（HTML + CSS + JavaScript 全部内联在一个文件里），文件名 index.html。
- 必须能在本地浏览器（Chrome/Edge）里双击直接打开运行。
- 必须离线可用：不加载任何外部链接（CDN、字体、图片、API、统计代码都不行），
  不要求网络，不依赖任何安装包或服务器。
- 不要引入框架（如 React/Vue）；原生 HTML/CSS/JS 即可，保证文件小、兼容好。
- 完成后必须自己用工具检查页面能否打开，并把打开方式告诉老师。

## 交互与界面（必须遵守）
- 目标用户是小学低中年级孩子：界面要简洁，一次只做一件事，避免信息过载。
- 文字要大（正文至少 20px）、按钮要大（至少 48px 高），适合手指点按和远距离看。
- 步骤引导要明确：每个操作都有提示，孩子知道「下一步该做什么」。
- 操作要有即时反馈：答对鼓励、答错引导，绝不只显示「错」。
- 全程简体中文，不出现英文界面文字。
- 动画要有但不能喧宾夺主，时长适中，不造成眩晕。

## 配色（必须遵守）
- 整体明亮、温暖、活泼：推荐浅色背景（米白/浅黄/浅蓝）+ 高饱和点缀色。
- 避免大面积深色、纯黑背景、刺眼的荧光色（纯红配纯绿等）。
- 对比度要足够，保证白板上投影也看得清。
- 红绿不用作唯一区分手段（色盲友好），可以配符号/文字。

## 内容与学科（必须遵守）
- 知识点必须准确，符合教育部课标对应年级的要求，不超纲、不超前。
- 数据、题目、选项必须是真实正确的，不得编造。
- 如涉及读音/发音，标注拼音或提供发音说明。
- 难度有梯度：从简单到复杂，或提供难度选择。

## 安全与隐私（必须遵守）
- 不收集、不上传任何学生个人信息（姓名、照片、输入内容都不行）。
- 不显示任何广告、外部链接、跳转。
- 不使用任何需要登录、注册、联网的组件。

## 交付与验收（必须遵守）
- 完成后向老师说明：文件在哪、怎么打开、覆盖了哪些知识点、怎么测试的。
- 交付前自己完整玩一遍，确认：知识正确、无卡死、无文字错误。
- 任何需要老师决策的地方（如某个交互方式拿不准），先问老师，不要自作主张。

## 常用信息
- 本地预览方式：双击 index.html 或拖进浏览器即可。
- 修改需求时直接说，我会在现有文件上改，不另起炉灶。
```

## 2. 逐条解读：为什么这么写？

### 2.1 技术栈 —— 为什么必须「单个 HTML 文件 + 离线」？

| 规矩 | 原因（老师视角） |
| --- | --- |
| 单文件 index.html | 发给学生就是一个文件：微信/QQ 发文件、拷 U 盘、发机房，都不会漏文件、不会打不开 |
| 双击即开 | 三年级孩子（或家长）不需要任何操作，双击就玩 |
| 离线、不加载外部资源 | 教室网络不稳定/没网也能用；不依赖别人的服务器，不会突然失效；也防止加载到不合适的网络内容 |
| 不用框架 | 文件更小、加载更快、兼容性更好，普通电脑/老设备都跑得动 |
| AI 自己测试 | 防止交付一个打不开的文件 |

> 💡 为什么特别强调「不加载外部资源」？因为很多 AI 默认会用 CDN 引字体、引图标库。
> 一旦教室断网，页面就「白屏」了。这条规矩直接杜绝这种坑。

### 2.2 交互与界面 —— 为什么字要大、引导要明确？

- 三年级孩子识字量有限、注意力短，**信息过载 = 劝退**。一次一个任务最好。
- 投影仪上看不清小字；触屏上按钮小了点不准。20px 正文、48px 按钮是底线。
- 「操作要有提示 + 即时反馈」是教学设计的基本原则（正强化），不是可选项。

### 2.3 配色 —— 为什么是「明亮温暖」而不是「高级深色」？

- 孩子喜欢明快、有生命力的颜色，深色界面在低龄场景容易显得沉闷压抑。
- 白板/投影时浅色底更清晰。
- 色盲友好是通用无障碍要求（红绿色盲在男生中约 8%）。

### 2.4 内容 —— 为什么强调「不超纲、不编造」？

- AI 偶尔会编造知识点或出「超前」的题。这条规矩强制它：
  1. 自查知识点是否准确、是否属于该年级；
  2. 宁可少出题，不出一错题。
- 如果拿不准，它应该**问你**，而不是硬编。

### 2.5 安全 —— 为什么「不收集信息」是硬规矩？

- 学生是未成年人，隐私红线绝对不能碰。AI 默认不会主动收集，但这条写进去，等于给 AI 划了明确的禁区，防止它「好心加个昵称登录功能」。

### 2.6 交付 —— 为什么要求 AI「交代 + 自测」？

- 让你验收有抓手：它说得出「怎么测试的」，说明真的试过。
- 「拿不准先问老师」把决策权还给你——AI 不该替你决定教学交互方案。

## 3. 模板怎么用：一个真实例子

配上这个 AGENTS.md 后，你只需要说一句：

> 「做一个两位数乘一位数的口算练习网页。」

AI 的默认理解会变成（对照模板自动套用）：

- ✅ 单文件、离线、双击即开
- ✅ 大字大按钮、中文、有鼓励反馈
- ✅ 明亮配色、一次一题、有难度梯度
- ✅ 不收集信息、不加广告
- ✅ 做完自测，并告诉你文件和用法
- ⚠️ 如果「口算还是竖式」拿不准 → 它会先问你

而如果没有 AGENTS.md，它可能给你一个需要联网、小字、深色、英文混杂的页面，你还得来回返工。

## 4. 想改规矩？改哪里？

模板里的每一节都可以按需调整：

| 你想改 | 改哪一节 |
| --- | --- |
| 目标用户是高中生 | 顶部「目标用户」+ 交互配色节 |
| 要联网查读音/发音 | 技术栈节放宽「必须离线」（注意权衡） |
| 要特定的配色（校徽色） | 配色节写上具体色值 |
| 科目是语文 | 内容节加「拼音、生字范围」等学科要求 |
| 要收集课堂练习结果 | 安全节改为「仅本地保存，不上传」 |

> 各学科、各年级的成品模板 → 第五部分《AGENTS.md 模板库》。

## 5. 小结

- 通用模板 = 技术栈（单文件/离线）+ 交互（大字/引导/反馈）+ 配色（明亮温暖）+ 内容（准确不超纲）+ 安全（不收集信息）+ 交付（自测并交代）。
- 每条规矩背后都是真实的课堂场景，不是空话。
- 改哪节、怎么改，看上面的对照表。
