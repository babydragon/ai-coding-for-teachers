# 01 · 什么是 AGENTS.md？为什么老师必须用它？

> 这是本指南最核心的一章。
> 看完你会明白：**AGENTS.md 是一张「贴在项目墙上的班规」，让 AI 不乱发挥，按你的要求干活。**

---

## 1. 先看一个「没有班规」的翻车现场

假设你直接对 Reasonix 说：

> 「做个数学练习题网页给学生做。」

没有 AGENTS.md 时，AI 可能自由发挥成这样：

| 你可能想的是 | AI 实际做出来的 |
| --- | --- |
| 一个网页，双击就能打开 | 需要联网才能用的在线版 |
| 三年级孩子用的，字要大 | 默认小字，大人看得清，孩子费劲 |
| 温暖明快的颜色 | 深色主题，孩子看着压抑 |
| 先教后练，有引导 | 直接甩一堆题 |
| 简体中文 | 偶尔冒出几句英文 |
| 单文件，方便发给学生 | 拆成七八个文件，学生根本打不开 |

**问题不在 AI 笨，而在你没给它「规矩」。** 你每次说的「要求」是临时的，AI 每一次发挥都靠猜。

## 2. AGENTS.md 是什么

**AGENTS.md** 是一个普通文本文件（Markdown 格式），分**两级**：一份放在 Reasonix 的全局数据文件夹（管所有项目，像校规），一份放在项目文件夹根目录（只管本项目，像班规）。本文先以项目级「班规」讲起，两级的关系见第 4 节。一份项目级 AGENTS.md 里面写清楚：

- 这个项目是干什么的；
- AI 干活时必须遵守的规矩（技术栈、交互、配色、语言、验收标准……）；
- 常用的命令和注意事项。

**它的特殊之处**：Reasonix **每次在这个项目里开会话，都会自动把 AGENTS.md 读进上下文**。也就是说，AI 一开工就先看班规，不用你每次重复强调。

> 💡 名字由来：`AGENTS.md` = 「给 Agent 看的说明文件」。
> 同类工具里也有叫 `CLAUDE.md`、`REASONIX.md` 的，作用一样。本指南统一用 **AGENTS.md**。

## 3. 教学类比：班规 vs 代课老师

| | 没有 AGENTS.md | 有 AGENTS.md |
| --- | --- | --- |
| 新会话 = 新代课老师 | 每次都要重新交代一遍「学生工具要离线、字要大、配色要明快……」 | 代课老师一进门先看墙上班规，自动照做 |
| 交代容易漏 | 说 10 条漏 3 条 | 规矩写全了，一条不落 |
| 老师不在时 | 学生乱来 | 规矩还在，学生不敢乱来 |
| 换人接手项目 | 全凭记忆，容易跑偏 | 打开文件就全明白 |

**一句话**：AGENTS.md 把你脑子里的「经验」变成项目里的「文件」，让 AI（和未来的你）都能看到、都能照做。

## 4. AGENTS.md 放在哪、长什么样

AGENTS.md **分两级**：全局（像校规）和项目（像班规）。Reasonix 两级都会自动读，先读校规、再读班规。

### 4.1 两级规矩：全局「校规」+ 项目「班规」

| | 全局 AGENTS.md（校规） | 项目 AGENTS.md（班规） |
| --- | --- | --- |
| 管什么 | 你**所有项目**的共同底线 | **这一个项目**的具体要求 |
| 典型内容 | 学生工具一律离线运行、全部简体中文、不给学生收集数据、动手前先讲计划 | 本项目是三年级竖式乘法、配色浅黄、按钮要大、先教后练 |
| 放在哪 | Reasonix 的全局数据文件夹（见 4.2） | 项目文件夹根目录 |
| 什么时候生效 | 每个项目、每个会话都自动读 | 只在对应的项目里自动读 |

**两者的联系与分工**：

- **先读校规，再读班规，两份都算数**。校规管「底线」，班规管「个性」。
- **共同的规矩只写一次**：凡是所有学生工具都要遵守的（离线、中文、安全），写进校规，不用在每个项目的班规里重复抄——省事，也省 Token 费用。
- **想全校立规矩 → 写校规；只想改这一个项目 → 写班规**。比如「这个游戏的难度要严格匹配三年级」，这是班规的事，不该写进校规。
- **班规可以比校规更具体，但一般不要和校规冲突**。冲突时 AI 会为难，验收时容易翻车。

### 4.2 全局「校规」放在哪、怎么创建

全局 AGENTS.md 放在 **Reasonix 的全局数据文件夹**（软件安装时自动创建的那个文件夹，一般不需要你手动去找位置）。最省事的两种办法：

- **让 AI 帮你建**：在 Reasonix 里直接说「帮我把这几条要求存成全局 AGENTS.md：……」，它会自动放到正确位置；
- **用桌面版设置界面**：在 Reasonix 桌面版的设置里一般能找到「全局记忆 / Instructions」入口，从那里可以查看或新建全局文件。

> 💡 检查全局文件是否生效：新开一个会话，问「全局规矩里对'给学生做的工具'有什么要求？」，AI 能复述出来就是生效了。

### 4.3 项目「班规」放在哪

**位置**：项目文件夹根目录，文件名就叫 `AGENTS.md`。

```
D:\学生工具\乘法小游戏\
├── AGENTS.md      ← 就放这里
├── index.html
└── (其他文件)
```

**一个最小例子**（完整模板见下一章）：

```markdown
# 乘法小游戏项目

这是一个给小学三年级学生使用的竖式乘法练习网页。

## 技术栈
- 必须：单个 index.html 文件（HTML+CSS+JavaScript 内联）
- 必须：双击用浏览器打开即可运行，不联网、不装任何东西

## 交互与界面
- 目标用户：8~9 岁孩子
- 字体要大、按钮要大，适合触摸屏
- 配色明亮温暖（浅黄/橙色系），避免深色和刺眼红绿
- 全部使用简体中文

## 注意
- 做完后必须自己打开页面测试一遍再交付
```

## 5. AGENTS.md 是怎么被读进去的？（原理，了解即可）

回顾第二章的 Agent 循环图：

```
你说：做一个乘法小游戏
  │
  ├─ Reasonix 自动读取项目里的 AGENTS.md（如果有）
  ├─ 把「AGENTS.md 内容 + 你的话」一起放进上下文
  └─ AI 干活时，脑子里始终带着这些规矩
```

所以：
- **AGENTS.md 写得越清楚，AI 越不会跑偏**；
- **AGENTS.md 写得越精炼，越省钱**（它每次都会被读一遍，太长等于每次多花 Token 费用）；
- 修改 AGENTS.md 后，**新开会话才生效**（AI 只读会话开始时的版本）。

## 6. 老师视角：AGENTS.md 帮你省了什么

1. **省打字**：规矩写一次，以后每句话就简短了——「按老规矩做一个除法游戏」即可。
2. **省纠错**：AI 不乱配色、不乱加功能，返工次数大幅减少。
3. **省担心**：学生工具的标准（离线、大字、安全）固化在文件里，AI 不会做出联网收集学生信息之类的东西。
4. **可传承**：换老师、换电脑、发给同事，把项目文件夹整个拷走，规矩跟着走。

## 7. 小结

- AGENTS.md **分两级**：全局「校规」管所有项目（Reasonix 自动管理，让 AI 存即可）；项目「班规」= 项目根目录的一个 Markdown 文件 = 给 AI 的「班规」。
- Reasonix 每次开会话自动读（先校规、后班规），AI 干活自带规矩。
- 共同底线写校规、写一次全校生效；个性要求写班规；写得清楚省心，写得精炼省钱。
