# 01 · 名词解释：AI Coding 基础词汇

> 这一章用大白话解释 AI 编程里最常见的名词。每个词都配一个「教学场景类比」，方便老师理解。
> 目标：读完这章，你能看懂别人聊 AI 编程时说的「Agent」「MCP」「Skill」，也知道以后怎么自己扩展。

---

## 0. 一句话总览

| 名词 | 一句话解释 | 教学类比 |
| --- | --- | --- |
| LLM / 大模型 | 会「读和写」文字的 AI 大脑 | 一位知识渊博、随叫随到的老师 |
| Prompt | 你给 AI 说的话（指令） | 你给学生布置的作业要求 |
| Token | AI 数文字的最小单位 | 数一篇文章有几个字 |
| Context（上下文） | AI 一次能记住多少内容 | 老师批作业时眼前能摊开的卷子量 |
| Agent（智能体） | 会自己「想、查、做、改」的 AI 助手 | 一位会主动备课、找资料、写教案、自己检查的实习老师 |
| Tool（工具调用） | Agent 可以调用的外部能力 | 老师用的计算器、词典、打印机 |
| MCP | 给 Agent 接新工具的「通用插座」 | 教室里的标准电源插座，什么电器插上就能用 |
| Skill | 一份写好的「工作方法说明书」 | 教研组沉淀下来的「备课流程规范」 |
| AGENTS.md | 放在项目里、每次开会 AI 都会读的「规矩清单」 | 贴在教室墙上的班规，学生（AI）一进门就能看见 |
| API / API Key | 程序的「门禁卡」 | 进机房要刷的校园卡 |
| 多模态 | 能看图、听音、认视频的 AI | 不光会看文字，还会看学生画的图 |

---

## 1. LLM（大语言模型）与大模型

**全称**：Large Language Model，大语言模型。

**大白话**：一个用海量文字「喂」出来的 AI 大脑。它最擅长一件事：**根据你前面说的话，预测下一句话最应该是什么**。把「预测下一个词」重复几万次，它就能写作文、写代码、翻译、解释数学题。

**教学类比**：就像一位读了几十万本书的老师，你问他什么他都能答上来，而且表达很自然。

**常见品牌**：DeepSeek、GLM（智谱）、通义千问、Kimi、GPT 等。Reasonix 本身不是大模型，它是个「组织大模型干活的工具」，可以接不同厂家的大模型（详见第二部分）。

**老师需要知道**：
- 不同大模型「聪明程度」不同，便宜的模型做简单任务够用，复杂的任务用更聪明的模型更稳。
- 大模型的能力不是越贵越好，关键是「指令说清楚 + 有规矩约束」——这正是 AGENTS.md 要解决的问题（第四部分）。

## 2. Prompt（提示词）

**大白话**：你输入给 AI 的那段话，就是 Prompt。可以是问题、命令、要求。

**教学类比**：给学生布置作业。「做几道题」是作业，「用竖式做 20 道多位数乘一位数，标出进位，字要工整」也是作业——后者学生知道该怎么做。**给 AI 的 Prompt 越具体，AI 交的作业越符合要求。**

**写作要点**（后面每一章都会用到）：
1. **角色**：你希望 AI 扮演谁（「你是一位小学三年级数学老师」）
2. **任务**：具体做什么（「做一个竖式乘法练习游戏」）
3. **要求**：明确边界（「运行在浏览器里」「不需要网络」「适合 8 岁孩子」）
4. **格式**：交付物长什么样（「一个单独的 index.html 文件」「按钮要大」）

## 3. Token（词元）

**大白话**：大模型不是按「字」数文字的，而是按「Token」数。一个 Token 大概等于：英文 1 个词，中文约 0.5~1 个词。

**教学类比**：批作文时你按「字数」统计，AI 按「Token」统计。

**老师需要知道**：
- 收费是按 Token 算的：输入、输出都花钱（一般输出更贵）。
- 一次性输入的内容越多，花的钱越多。所以 AGENTS.md 要写得精炼——它每次开会（每个新会话）都会被读一遍，写得啰嗦等于每次都多花钱。

## 4. Context / 上下文窗口

**大白话**：大模型一次能「同时看」多少内容，超过的部分就记不住了（会被压缩或遗忘）。Reasonix 会帮你自动管理：内容太多时会自动「压缩纪要」，保证对话能继续。

**教学类比**：批作业时桌面能摊开的卷子有限。摊不下了就得把前面的先收起来（压缩成要点）。

**老师需要知道**：
- 一个项目里的会话太长，AI 可能忘掉最开始的要求 → 这正是 AGENTS.md 存在的意义：**让关键规矩不依赖「记住」，而是每次自动看到**。

## 5. Agent（智能体）

**全称**：AI Agent，AI 智能体。

**大白话**：不只是一个「会说话的 AI」，而是一个**能自己动手干活的 AI**。它会：理解任务 → 制定计划 → 调用工具（读写文件、运行程序、查资料）→ 看结果 → 修改 → 再试 → 直到完成，然后向你汇报。

**教学类比**：不是「你问一句、AI 答一句」的问答，而是「你把一件事交给 AI，它像一位实习老师一样，自己查资料、自己写教案、自己改错、最后把成品交给你」。

**为什么说 Agent 是「智能体」而不是「聊天机器人」**：因为它有「行动能力」——它真的能读写你电脑上的文件、真的能运行程序看结果，而不只是嘴上说说。

**Reasonix 就是一个 Agent 工具**：你给它一个任务，它在你的电脑上真刀真枪地干（建文件、写代码、跑测试），干完给你看结果。原理详见《02 · Agent 编码原理》。

## 6. Tool / 工具调用（Function Calling）

**大白话**：Agent 除了「动嘴」（生成文字），还能「动手」——调用一些预先定义好的工具，比如「读写文件」「运行命令」「搜索网页」。

**教学类比**：老师的工具箱。Agent 是老师，Tool 是计算器、词典、打印机。老师算不出来时用计算器，而不是硬编。

**Reasonix 默认带这些工具**（举例）：

| 工具 | 作用 | 教学类比 |
| --- | --- | --- |
| `read_file` / `write_file` | 读写项目里的文件 | 翻开/合上备课本 |
| `edit_file` | 精准修改某一段 | 用红笔改教案的某一段 |
| `bash` | 运行命令（装软件、跑程序） | 用打印机/复印机 |
| `grep` / `glob` / `ls` | 搜索文件内容、列文件 | 查资料时翻目录 |
| `web_fetch` | 抓取网页内容 | 上网查资料 |
| `task` / `fleet` | 派多个子任务并行干 | 请几位助教分头备课 |

## 7. MCP（Model Context Protocol，模型上下文协议）

**全称**：Model Context Protocol，由 Anthropic 提出的开放协议。

**大白话**：一个**统一的「插座标准」**。以前给 AI 加一个新能力（比如查天气、连学校数据库），每家都要单独做一个专用接口；现在只要按 MCP 标准做一个「插座」，任何支持 MCP 的 AI 工具（包括 Reasonix）插上就能用。

**教学类比**：教室里的标准电源插座。以前每个电器都要配自己的专用插口，现在统一成国标插座，买什么电器都能插。

**老师能拿来干什么**：
- 给 Reasonix 接入现成的 MCP 服务器，比如连一个「题库查询」服务、连一个「图生视频」服务，AI 就能直接调用这些能力。
- 不需要自己写代码，别人做好 MCP 服务器，你在配置文件里加几行就能接上。

**在 Reasonix 里怎么配**：在 Reasonix 的配置文件（`reasonix.toml`）里加一段 `[[plugins]]`（详见第二部分或工具文档）。Reasonix 的命令行也提供 `reasonix mcp add ...` 来管理。

## 8. Skill（技能）

**大白话**：一份**写好的「工作方法说明书」**。它告诉 Agent：「遇到这类任务，按这个流程做，注意这些事项。」Skill 里可以包含步骤、规则、检查清单，甚至可以让 Agent 去调用其他工具。

**教学类比**：教研组把「如何备一节公开课」沉淀成一份流程规范：先定目标 → 设计环节 → 准备教具 → 试讲 → 修改。新老师照着规范做，就不会乱来。Skill 就是给 Agent 的「备课流程规范」。

**老师能拿来干什么**：
- 把「我做学生练习页的固定要求」存成一个 Skill，以后一句话就能让 AI 按这个规范干活。
- 网上/别人分享的 Skill 可以直接装（Reasonix 的「技能安装」功能）。

## 9. AGENTS.md

**大白话**：放在项目文件夹根目录的一个普通文本文件（Markdown 格式），里面写「这个项目是干什么的、有哪些规矩、AI 干活时要注意什么」。**Reasonix 每开一个新会话都会自动读这个文件**，相当于每次开会前先让 AI 看一遍班规。

**教学类比**：教室墙上的班规。不管今天是不是新老师代课，一进门就能看到规矩，不会因为「没人提醒」就乱来。

**这是本指南的核心**：第四部分专门讲怎么给「学生用的工具」写好 AGENTS.md，第五部分给了多套可直接复制的模板。

## 10. API 与 API Key

**全称**：Application Programming Interface，应用程序接口。

**大白话**：
- **API**：程序之间互相调用的「服务窗口」。Reasonix 通过 API 向大模型厂商请求「帮我生成一段文字」。
- **API Key**：你的「门禁卡/账号密码」。调用大模型厂商的 API 需要这张卡，**卡要保密**。

**教学类比**：API 是学校教务系统开放的成绩查询窗口，API Key 是你的登录账号密码。用 Reasonix 前，需要先去大模型厂商（如 DeepSeek）官网注册、充值、拿到 API Key，然后填进 Reasonix（详见第二部分）。

## 11. 多模态（Multimodal）

**大白话**：能同时处理多种信息（文字、图片、声音、视频）的 AI 能力。

**教学类比**：普通 AI 只看得懂文字版教案；多模态 AI 还能看学生手写的作业照片、听朗读录音、看懂几何图形。

**老师能拿来干什么**：
- 拍照给学生手写的计算过程，让 AI 判断哪里错了。
- 让 AI 根据一张示意图生成讲解。
- 注意：多模态能力取决于你选的模型，配置模型时可以留意支持情况。

## 12. 其他常见词（看一眼有印象即可）

| 名词 | 大白话 |
| --- | --- |
| Git / GitHub | 文件的「版本管理」系统，记录每次修改，可回退。Reasonix 会自动帮你做简单的版本记录 |
| Markdown（.md） | 一种轻量排版格式，用 `#`、`**` 等符号排版，本文档就是 Markdown 写的 |
| 前端 / 后端 | 前端=用户看到的界面（网页），后端=背后干活的程序。给学生的工具一般只做前端（浏览器打开） |
| HTML / CSS / JavaScript | 网页的骨架 / 皮肤 / 行为。做学生小游戏主要靠这三种 |
| 离线运行 | 不联网也能用。学生工具建议做成离线运行（见第四部分规矩） |
| 部署 | 把一个工具放到别人能访问的地方（如发到班级群、挂到服务器） |

---

## 小结

- **LLM** 是大脑，**Prompt** 是说话，**Agent** 是能动手干活的助手。
- **Tool** 是 Agent 的手，**MCP** 是通用插座，**Skill** 是工作规范。
- **AGENTS.md** 是贴在项目墙上的班规，是本指南的「主角」之一。
