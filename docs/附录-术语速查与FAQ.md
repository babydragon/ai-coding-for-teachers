## 2. 常见问题（FAQ）

### Q1：我完全不会编程，能学会吗？
能。Reasonix 帮你写代码，你只需要把需求说清楚（这正是本指南教你的）。你不需要懂 HTML/JS，只需要懂「你要做一个什么样的工具」。

### Q2：做一个小工具要花多少钱？
很小。以 DeepSeek 为例，做一个单文件小游戏的任务，通常几分钱到几毛钱。Reasonix 界面会实时显示花费，可以随时看。

### Q3：AI 做的东西能放心给学生用吗？
按本指南流程：**AGENTS.md 定规矩 → 验收时自己玩一遍 → 确认知识点正确**。AI 是「初稿」，你是「终审」。尤其知识点准确性，务必抽查几道题。

### Q4：AI 会乱删我的文件吗？
Reasonix 默认在 Ask/Auto 模式下会先征求同意；只动当前项目文件夹里的文件。建议重要文件先备份。

### Q5：AGENTS.md 每次都读，会不会很浪费？
会占少量上下文。所以模板设计得精炼，只写必须的规矩。相比「AI 乱发挥导致返工」的浪费，这点成本可以忽略。

### Q6：可以多个人（多个老师）共用一个项目吗？
可以。AGENTS.md 就是「交接班」的关键：谁接手都能通过它快速理解项目规矩。注意别在文件里写密钥和隐私。

### Q7：学生工具怎么发给学生？
单文件最方便：微信/QQ 发文件、拷 U 盘、放学习平板、挂机房电脑都行。双击即开，无需安装。

### Q8：Reasonix 支持哪些大模型？
常见的中外模型大多支持（DeepSeek、GLM、通义、Kimi、GPT 等），在设置里添加服务商、填 API Key 即可，可以同时配多家随时切换。

### Q9：改完 AGENTS.md 为什么没生效？
旧会话不会重读 AGENTS.md。改完文件后**新开一个会话**再试。

### Q10：AI 中途问我问题，我要回答吗？
要。它拿不准的时候问你，说明它在认真做事（而不是瞎猜）。回答越明确，结果越符合预期。

### Q11：万一 AI 做的东西打不开/报错怎么办？
把报错信息原样发回给 AI：「打开 index.html 白屏，控制台报错 XXX」。它能根据错误自查修改。再不行，换个模型试试（更聪明的模型排查更稳）。

### Q12：这份文档里的模板我能随便改吗？
能，而且鼓励改。模板是起点不是终点，按你的年级、科目、学校要求改造成你自己的版本（见第五部分第 5 节）。

## 3. 常用命令速记（老师可选学）

如果你愿意在 Reasonix 的命令行/输入框里用一点快捷方式：

| 你想做的事 | 怎么说/怎么输入 |
| --- | --- |
| 让 AI 分析项目并生成 AGENTS.md | 输入 `/init` |
| 开新会话 | 顶部「+」新建会话 |
| 切换模型 | 点底部状态栏的模型名 |
| 让 AI 审查当前改动 | 输入 `/review` |
| 让 AI 跑项目测试 | 输入 `/test` |
| 查看工具说明 | 输入 `/help` 或问 AI |

## 4. 建议的学习路径回顾

```
第 1 遍（建立认知）：名词解释 → Agent 原理

第 3 遍（进阶）：AGENTS.md 通用模板 → 安装更新 → 模板库选型
```
