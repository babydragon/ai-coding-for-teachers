# 01 · 动手做：竖式乘法小游戏

> 这一章是你第一次「完整走一遍」：从一个知识点，到给 AI 下指令，到 AI 做出一个能给学生用的小游戏。
> 成品就在本仓库的 `examples/竖式乘法游戏/index.html`，你可以先打开玩一下，再按本章自己从零做一遍。
> 预计用时：30 分钟。

---

## 1. 这节课我们要做什么

**知识点**：小学三年级数学 —— 多位数 × 一位数（竖式计算），重点理解：
- **数位对齐**（个位对个位、十位对十位……）
- **从个位乘起，满十进一**（进位怎么写、加到哪一位）

**产品形态**：一个在浏览器里打开就能玩的交互小游戏（HTML 单文件，离线可运行）。

**亮点（带动画）**：
- 点击「开始」，题目出现，学生用竖式逐步计算；
- 每一步都有动画演示：对齐、相乘、写积、进位的小箭头和数字动效；
- 答对了有鼓励反馈，答错了有提示引导（而不是直接给答案）。

## 2. 第一步：建项目文件夹

👉 动手做：

1. 在你的电脑上建一个文件夹，例如：`D:\学生工具\竖式乘法游戏`。
2. 打开 Reasonix，新建一个会话，选择这个文件夹作为项目。

> 一个项目 = 一个工具，文件都在里面，AI 不会乱跑到别的地方。

## 3. 第二步：给 AI 下指令（Prompt）

把下面这段直接复制进 Reasonix 输入框，发送：

```
在这个项目里做一个给小学三年级学生用的竖式乘法练习小游戏。

要求：
1. 只有一个 index.html 文件（HTML+CSS+JavaScript 都写在一个文件里），
   双击用浏览器打开就能玩，不需要网络，不需要安装任何东西。
2. 知识点：多位数 × 一位数（例如 36×7、245×3），随机出题，
   乘数（一位数）范围 2~9，被乘数 2~3 位。
3. 学生需要自己完成竖式：输入每一步的乘积和进位，
   或者用点选的方式逐步完成（选一种你觉得对三年级孩子更友好的交互方式）。
4. 要有动画：演示数位对齐、从个位乘起、满十进一、进位加到上一位的过程。
   动画要慢、要清楚，每一步都有文字提示（例如"3×7=21，写 1 进 2"）。
5. 界面适合小学低年级孩子：大按钮、大字体、圆角卡片、明亮鲜艳但不刺眼的配色、
   可爱的卡通元素，避免过于花哨影响专注。
6. 答对时给正面鼓励（换着花样表扬），答错时给出提示引导，不直接批评。
7. 做一个简单的计分（比如答对几题得几颗星），结束有总结。
8. 所有文字都用简体中文。
9. 做完后告诉我文件在哪、怎么打开，并且告诉我你是怎么测试的。
```

> 这段指令里的要求（离线、单文件、配色、交互、反馈方式……）就是第四部分 AGENTS.md 要帮你「固化」的东西——现在先手动写一遍，体会一下。

## 4. 第三步：AI 干活时，你干什么

发送后，你会看到 AI 开始行动（第二章讲过的循环）：

| 你看到的 | 说明 |
| --- | --- |
| AI 说它先规划 | 它会把任务拆成「搭页面 → 出题逻辑 → 竖式交互 → 动画 → 测试」 |
| AI 创建文件 | 在项目文件夹里生成 `index.html`（如果提示允许，点允许） |
| AI 修改文件 | 反复调整界面、动画、交互细节 |
| AI 自己测试 | 它可能会用工具在本地打开/检查页面（在 Ask 模式下会先问你） |
| AI 交作业 | 告诉你文件路径和打开方式 |

**你该做的**：
1. 保持 Ask 或 Auto 模式，偶尔看一眼它要动什么文件。
2. 觉得哪里不对，随时打断它改要求（比如「动画太快了」）。
3. 等它说「完成」后，自己动手验收（下一步）。

> 如果 AI 中途停下来问你问题（比如「交互方式 A 还是 B？」），按你的判断回答即可。这正是它「不瞎猜、问你拍板」的表现。

## 5. 第四步：验收（这步很重要）

👉 动手做：

1. 找到项目文件夹里的 `index.html`，**双击用浏览器打开**（Chrome / Edge 都行）。
2. 按「老师三连问」检查：
   - **知识对不对**：随机算几道题，用纸笔核对竖式每一步是否正确；
   - **孩子能不能玩**：字够不够大？按钮好不好点？动画看得懂吗？
   - **有没有坑**：有没有让人卡死、点不到、看不懂的环节？
3. 发现问题，直接回 Reasonix 说，例如：
   > **「第三题的进位动画里，进位数字飞的位置不对，应该落在十位上。」**
   AI 会修，修完你再打开刷新验收。
4. 通过后，把 `index.html` 发给学生（班级群 / 学习平板 / 机房电脑都行）——因为是单文件，一个文件就能跑，很好分发。

## 7. 复盘：这次任务里，什么让你省了力？

做完一遍，你会发现：

| 以前（如果自己学编程做） | 现在（用 AI 做） |
| --- | --- |
| 要学 HTML/CSS/JavaScript 语法 | 只写中文需求 |
| 要自己调试一堆报错 | AI 自己测、自己改 |
| 做动画很费劲 | 一句话「带动画演示进位」 |
| 一个游戏做几周 | 一个晚上搞定初版 |

但也别忽视「坑」：
- **AI 有时会理解偏**（比如动画太快、交互对孩子太难）→ 所以验收环节不能省；
- **AI 有时代码有小 bug** → 所以「自己先玩一遍」是铁律；
- **指令越清楚，AI 越少发挥** → 这就是为什么要有 AGENTS.md。
