# 06-03 · 让 AI 干更重的活：安装依赖的正确姿势

> 前两章的工作（做小游戏、整理文本）都不需要额外安装任何东西。这一章讲：当 AI 提出「要装点什么」时，怎么判断、怎么处理。
> 目标：读完这章，你能区分「真需要装」和「AI 偷懒想装」，并掌握两条安全的安装路径。

---

## 0. 一句话总览

| 问题 | 答案 |
| --- | --- |
| AI 说「需要装 Python/Node.js」，是真的吗？ | 多数情况下**不是必须的**，先让 AI 换不用装的办法 |
| 什么情况下才真的要装？ | AI 要跑测试脚本、处理特殊文件格式、连外部工具时 |
| 怎么装才安全？ | 两条路：① AI 生成安装说明你/网管执行；② 你授权后 AI 直接装（需你在电脑上点确认） |
| 装东西要不要审批？ | 要。属于「执行」类申请，用「三问口诀」判断（见第二部分的「如何判断 AI 的申请」） |

---

## 1. 先泼冷水：AI 说「要装」，常常是它偷懒

前面（第二部分）我们已经确认：**老师的基础功能，Windows 自带的 PowerShell 就能搞定，不需要装任何东西。**

AI 提出「需要安装 Python」时，先别急着答应。多数情况它只是习惯性地想用自己熟悉的工具。你可以直接说：

> 请不要安装任何软件。电脑上没有 Python，你换一种不依赖 Python 的做法。

常见的「假需求」：

| AI 的说法 | 真相 | 你可以怎么说 |
| --- | --- | --- |
| 「需要 Python 来检查代码」 | 小游戏用浏览器打开就能验证 | 「用浏览器打开验证就行」 |
| 「需要 Node.js 来运行脚本」 | 大多数任务有替代方案 | 「不要装，换别的方法」 |
| 「需要安装依赖包」 | 单文件 HTML 不需要依赖 | 「保持单文件，不加依赖」 |

> 💡 **好习惯：** 在项目里的 AGENTS.md（第四部分）写一条规矩——「不假设电脑装了 python/node，也不要让老师安装任何软件」，AI 就很少再提了。

---

## 2. 什么时候是真的要装？

少数情况装东西是合理的：

| 场景 | 要装什么 | 为什么 |
| --- | --- | --- |
| AI 要跑一段自动化检查脚本 | Python | 需要执行脚本来验证逻辑 |
| 你要管理项目版本、推送到 GitHub | Git | 版本管理工具 |
| 要用浏览器自动化（agent-browser 等 skill） | Node.js | skill 运行环境 |
| 要连 OCR / 题库等外部能力 | 对应的 MCP 服务器 | 见 [下一章 MCP](../06-进阶使用/04-让AI连接更多.md) |

**判断标准：** 装完之后，它帮你省下的时间，值不值得一次安装的折腾？对多数老师来说，**前三个都可以先不装**——脚本检查能用浏览器替代，版本管理可以以后再说，浏览器自动化属于进阶玩法。

---

## 3. 安全安装的两条路

如果确实要装，记住：**装软件是系统级操作，等于让 AI 动你电脑的「水电总闸」，必须走审批。**

### 路 A（推荐）：AI 生成安装说明，你或网管执行

> 我同意装 Python。但请你把安装步骤写清楚，我确认后自己装。

AI 会给你一段类似这样的说明（或者一个 .bat 文件）：

```bat
winget install Python.Python.3.12
```

你（或学校网管）看了没问题，双击运行即可。

**适合：** 任何情况，尤其是你不确定装什么、装哪一版时。**风险最低，AI 全程不碰你的系统。**

### 路 B（进阶）：你授权后，AI 直接装

Reasonix 里 AI 可以通过「运行命令」工具执行安装命令，但**每一步都会弹申请**，需要你点击批准；Windows 还会弹 UAC 窗口要你确认。

> 可以装 Python，用 winget 装，装最新稳定版。命令我先看看再批准。

**适合：** 你已经很熟悉 Reasonix、且确实需要 AI 边装边继续干活时。**注意：** 安装过程会改系统设置（PATH、注册表），装完可能需要重启 Reasonix 才生效。

---

## 4. 用「三问口诀」判断安装申请

第二部分教过「如何判断 AI 的申请」的三问口诀，装软件正好是最典型的案例：

| 三问 | 装软件时的对照 |
| --- | --- |
| ① 只读还是要改动？ | 装软件是**执行 + 改系统**，最重的一类申请，默认要警惕 |
| ② 文件在不在项目文件夹内？ | 装软件动的是**系统盘**（C 盘 Program Files 等），不在项目内，风险高 |
| ③ 命令看得懂吗？ | 看不懂的命令绝不批准；`winget install` 这类看得懂、来源明确（微软官方源）的才考虑 |

**一句话：装软件 = 高风险操作，默认拒绝，确实需要时走路 A（自己装），或路 B 但每一步看仔细。**

---

## 5. 装完怎么验证

- 让 AI 运行一条验证命令（如 `python --version`），确认装上了；
- 确认 Reasonix 没报错、新功能能用了；
- 记下装了什么、装在哪，以后出问题好排查（也可以写进项目 AGENTS.md 的「常用信息」）。

---

## 6. 小结与下一章

- **默认不装**：多数需求有替代方案，先让 AI 换办法；
- **真需要装**：优先路 A（AI 出说明、自己执行），路 B（AI 直接装）要步步审批；
- **装软件是最重的申请**，三问口诀全用上。
