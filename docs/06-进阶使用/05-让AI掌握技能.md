# 06-05 · 让 AI 掌握你的做事方法：Skill 入门

> MCP 给 AI 加「工具」，Skill 则是给 AI 加「做事方法」。这一章讲 Skill 是什么、和 AGENTS.md 有什么区别、老师怎么用现成的。
> 目标：读完这章，你能分清「规矩、工具、方法」三件事，并知道从哪里找老师能用的 Skill。

---

## 0. 一句话总览

| 问题 | 答案 |
| --- | --- |
| Skill 是什么？ | 一份写好的「工作方法说明书」：遇到某类任务，AI 照着这套方法做 |
| 和 AGENTS.md 什么区别？ | AGENTS.md 是**每时每刻的规矩**（班规）；Skill 是**做某类活时的流程**（操作手册） |
| 和 MCP 什么区别？ | MCP 是**工具**（有没有这个能力）；Skill 是**方法**（怎么用能力做事） |
| 老师用得上吗？ | 用得上：做 PPT 演示文稿、文本整理、格式转换等都有现成 Skill |
| 要自己写吗？ | 不必须。先用现成的；想沉淀自己的流程时再写（最后一节） |

---

## 1. Skill、AGENTS.md、MCP——一张表分清

| | 是什么 | 类比 | 什么时候起作用 |
| --- | --- | --- | --- |
| AGENTS.md | 项目的**规矩**（边界、风格、禁忌） | 班规：一进门就要遵守 | 每次对话都读 |
| Skill | 某类任务的**做法**（步骤、模板、检查清单） | 操作手册：做这类活时照着做 | 遇到匹配的任务时调用 |
| MCP | 外部的**工具/能力** | 教具柜：领了才能用 | 需要该能力时调用 |

**例 1：做「竖式乘法小游戏」**
- AGENTS.md 说：单文件 HTML、按钮要大、离线可用（**规矩**）；
- Skill 说：先生成题目 → 做竖式对齐 → 加进位动画 → 用浏览器验证（**方法**）；
- MCP 说：需要的话可以连一个「查数学教材」的工具（**工具**，本例不需要）。

**例 2：做一份「家长会 PPT」**（更贴近日常的对照）
- AGENTS.md 说：风格简洁、不放学生姓名、只用你给的素材（**规矩**）；
- Skill 说：先写大纲 → 按页面排版 → 每页只讲一件事 → 检查文字有没有溢出（**方法**）；
- MCP 说：需要的话可以连一个「联网查数据」的工具，把班级数据做成图表（**工具**，本例可选）。

## 2. 老师现在就用得上的 Skill

Reasonix 里可以安装现成 Skill，其中和老师关系最大的，先说**做 PPT** 这个（后文详讲）：

| Skill | 干什么的 | 老师什么时候用 |
| --- | --- | --- |
| **做 PPT 演示文稿**（pptx skill） | 把「帮我做一份 PPT」变成真实的 .pptx 文件，带排版、配色、演讲备注 | 要开家长会、教研分享、给学生做知识点课件时 |
| 浏览器自动化（agent-browser） | 让 AI 真的打开浏览器点按钮、填表、截图 | 想自动验证做好的网页、或帮你在网页上填资料 |
| 文本/文档处理类 | 按固定流程整理文本、转换格式 | 日常文本工作（上一章）的进阶版 |
| 项目初始化（init） | 分析一个项目，自动写好 AGENTS.md | 从零开始一个新项目时 |

> 💡 装 Skill 的方式和装 MCP 类似，Reasonix 里有 Skill 列表可以直接浏览启用。**注意看 Skill 描述**，判断它是不是正好干你要的活。

**怎么知道有哪些 Skill？** 在 Reasonix 里查看「技能（Skills）」列表，或直接问 AI：「你有哪些现成的技能可以帮老师干活？逐个介绍适合什么场景。」

### 2.1 实例：让 AI 帮你做一份 PPT

这是目前社区和官方里**评价最高、也最贴近老师**的 Skill 例子——Anthropic 官方出品的 `pptx` 技能（在其官方 skills 仓库里，属于生产级能力，Claude.ai 付费版也内置了它）。你只需要说：

> 用 pptx 技能做一份家长会 PPT，6 页：1）本学期班级概况；2）语文学习重点；3）数学学习重点；4）给家长的建议；5）需要家长配合的事；6）答疑安排。风格简洁大方，每页标题+3 条要点，不加学生姓名。

AI 会调用 skill，按里面的步骤（写大纲 → 排版 → 加演讲备注 → 自查）生成一份**真正的 .pptx 文件**，你下载后用 PowerPoint/WPS 打开即可再改。

关于这个 Skill，有三件事老师要知道：

1. **它需要电脑装 Node.js**（做 PPT 的底层工具是 Node 的）。这正好用上 [上一章「装依赖的正确姿势」](03-让AI干更重的活.md)——默认让 AI 生成安装说明、你确认后执行；装一次以后都能用。
2. **纯文本模型也能做**：生成 .pptx 是「按脚本排版」的活，不一定需要 AI「看懂图」。所以你现在用的 deepseek 这类纯文本模型就能做出规整的 PPT。
3. **视觉模型做得更漂亮**：如果模型能「看」渲染出来的页面效果（有没有文字溢出、对齐歪了），版式质量会明显更高。这与 [日常文本工作第 4 节](02-日常文本工作.md) 讲的「图片处理看模型」是同一件事——想追求更精致，可以换一个视觉模型。

> 🔍 想找更多？社区里还有不少 PPT 类 skill，例如「dashi-ppt-skill」（支持导出成网页版演示）和中文的「gpt-image2-ppt-skills」（可以照着现有课件模板改版式）。挑的时候用 [第 4 章「怎么挑」](04-让AI连接更多.md) 的三看原则：维护活跃度、用途匹配、来源可信。

## 3. 用好 Skill 的姿势

1. **先问 AI 有什么**：让 AI 自己介绍它会的技能，比自己翻列表快；
2. **按场景触发**：Skill 通常在你发出匹配的任务时自动被调用，也可以点名要它用；
3. **看它怎么工作**：Skill 被调用时，AI 会按里面的步骤走——你从对话里能看到它的思路（先做什么、再做什么），这也是学习的好机会；
4. **和规矩配合**：Skill 管「怎么做」，AGENTS.md 管「不能做什么」，两个都要有。

---

## 4. 进阶玩法：把自己的流程沉淀成 Skill

你经常让 AI 做同一类事（比如「生成 20 道口算题」），可以把它变成自己的 Skill，以后一句话就触发。写法很简单：

> 把我的这个做法存成一个技能：以后我说「出口算题」，你就按这个流程做——1）随机出 20 道两位数乘一位数；2）做成单文件 HTML；3）用浏览器打开验证 5 道题；4）告诉我怎么用。

AI 会把它整理成一份 Skill 文件保存下来。下次直接说「出口算题」即可。

> ⚠️ 这属于进阶玩法，**不是必须**。先用现成的，用熟了再沉淀自己的——就像先学别人教案，再写自己的。

---

## 5. 小结与下一章

- Skill = 做事方法（操作手册），AGENTS.md = 规矩（班规），MCP = 工具（教具）；
- 老师先从「问 AI 有哪些技能」开始，用现成的；
- 用熟了，再把常用流程沉淀成自己的 Skill。
