# 06-04 · 让 AI 连接更多：MCP 入门

> 前面几章里，AI 能自己读文件、写文件、上网抓内容。这一章讲怎么给 AI「接上新的能力」——这就是 MCP。
> 目标：读完这章，你知道 MCP 能干什么、怎么挑现成的、怎么装，以及哪些情况**不要**自己折腾。

---

## 0. 一句话总览

| 问题 | 答案 |
| --- | --- |
| MCP 是什么？ | 让 AI 连接外部工具的「标准插座」（基础部分讲过：教室里的标准电源插座） |
| 能干什么？ | 读 PDF、OCR 图片、查资料、连数据库、操作浏览器…… 相当于给 AI 装新「器官」 |
| 老师用得上的有哪些？ | 文件处理类（PDF 读取）、OCR 类（图片转文字）、搜索类（联网查资料） |
| 怎么装？ | 在 Reasonix 里「添加 MCP 服务器」，填一个地址/命令就行，AI 也会提示你 |
| 要会写代码吗？ | 完全不用。装现成的就行，自制属于程序员的事 |

---

## 1. MCP 到底解决了什么问题？

没有 MCP 时，AI 的能力是**固定的**：读文件、写文件、上网抓取…… 都是 Reasonix 自带的。

有 MCP 之后，AI 的能力是**可扩展的**：你想让它读 PDF？装一个 PDF 的 MCP。想让它认图片里的字？装一个 OCR 的 MCP。想让它操作浏览器？装一个浏览器的 MCP。

**教学类比：** Reasonix 自带的工具是「教室里本来就有的教具」；MCP 是「从教具柜里新领的器材」——领了什么，AI 就会用什么，不用换 AI。

---

## 2. 老师现在就用得上的 MCP（三张图看懂）

| 类别 | 典型 MCP | 适合的任务 | 对应章节 |
| --- | --- | --- | --- |
| 文件处理 | PDF 读取类 | 把 PDF 里的文字/表格提取出来整理 | [日常文本工作](02-日常文本工作.md) |
| 图片识别 | OCR 类 | 手写照片、截图转成文字 | [日常文本工作第 4 节](02-日常文本工作.md) |
| 联网搜索 | 搜索类 | 让 AI 查最新资料、政策、题目出处 | 任意需要资料的任务 |

> ⚠️ 重要：MCP 是「给 AI 加工具」，不是「AI 自动就有了」。装了之后，AI 会主动提议用这些工具——这时弹出的申请（「请求使用 MCP 服务器」）要用第二部分的「三问口诀」判断：它读的是哪个文件？动的是不是项目内的东西？

---

## 3. 怎么挑现成的 MCP？

**原则：先搜「现成的」，别想「自己造」。**

1. 在 Reasonix 里看「MCP 服务器」列表（通常有推荐/可搜索的现成项）；
2. 网上搜「MCP 服务器 列表」或「awesome MCP」，有海量现成选择；
3. 挑的时候看三个东西：
   - **维护活跃度**：最近还在更新吗？（GitHub 星数、更新时间）
   - **用途匹配**：是不是正好干你要的活（读 PDF？OCR？）
   - **安全性**：来源是否可信（官方出品优先），申请时看清它要访问什么

**老师最常用的判断：** 如果是为了「读 PDF / 认图片 / 查资料」这类通用需求，优先选**官方或知名厂商出的 MCP**，别选来路不明的。

---

## 4. 怎么装一个 MCP？

在 Reasonix 里通常两步：

1. 打开「MCP 服务器」设置，点「添加」；
2. 按提示填**服务器的地址**（远程的填网址，本地的填命令），保存。

AI 检测到新 MCP 后，在合适的时候会主动提议使用。**装的过程 AI 会引导你**，遇到要运行的命令，按 [上一章安装依赖](03-让AI干更重的活.md) 的方法判断和处理即可。

> 💡 装 MCP 本质也是「让 AI 动系统/连外部」，所以同样适用三问口诀：**它要连哪里？要读什么？我批准了吗？**

---

## 5. 和上一章「图片处理」接上

在 [日常文本工作第 4 节](02-日常文本工作.md) 讲过：图片里的文字怎么变成文本，两条路——换视觉模型，或装 OCR 工具。

**OCR 工具就是典型的 MCP：** 你不需要换模型，装一个 OCR 类 MCP，纯文本模型的 AI 也能「读」出图片里的字。这就是 MCP 最实在的价值：**花最小的代价，给现有 AI 补上缺失的能力。**

---

## 6. 什么时候**不要**自己折腾 MCP？

| 情况 | 建议 |
| --- | --- |
| 只是想读几个 PDF/图片 | 先试试不装：把 PDF 里的文字复制粘贴给 AI 就行；图片先试视觉模型 |
| 现成的 MCP 够用 | 不折腾，直接用 |
| 需要「自制一个工具」 | 这是程序员/进阶者的活，老师别碰——找现成的，或让 AI 帮你搜 |
| 申请里出现看不懂的命令/来源 | 拒绝，回退到「不装」方案 |

**一句话：老师用 MCP 的正确姿势是「挑现成的、装官方的、看清申请」，不是「自己造」。**

---

## 7. 小结与下一章

- MCP = 给 AI 加工具的「插座」，装现成的即可，不用写代码；
- 老师最常用：PDF 读取、OCR、联网搜索三类；
- 安装/使用都要过「三问口诀」，来路不明的直接拒绝。
