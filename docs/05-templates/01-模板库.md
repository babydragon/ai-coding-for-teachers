# 01 · AGENTS.md 模板库

> 这一章给不同场景的现成 AGENTS.md 模板，老师按「受众 × 科目 × 工具类型」快速挑选，拿来即用。
> 所有模板的完整可复制文件都在本指南的 [`templates/`](../../templates/) 文件夹里，文件名见下表。

---

## 1. 怎么选模板：一个「选择题流程」

```
第 1 步：目标用户是谁？
   → 小学低年级（1~2 年级）   → 模板 A：低年级通用
   → 小学中年级（3~4 年级）   → 模板 B：中年级通用（本指南主模板）
   → 小学高年级（5~6 年级）   → 模板 C：高年级通用
   → 初中 / 高中              → 模板 D：中学通用

第 2 步：什么科目？
   → 数学   → 叠加「数学版」要求
   → 语文   → 叠加「语文版」要求
   → 英语   → 叠加「英语版」要求
   → 其他   → 用通用模板，自己加两条学科要求

第 3 步：什么类型的工具？
   → 练习/刷题   → 叠加「练习类」要求（出题、判题、计分）
   → 游戏化学习   → 叠加「游戏类」要求（关卡、反馈、奖励）
   → 教学演示     → 叠加「演示类」要求（大屏、动画、逐步讲解）
   → 学习资料页   → 叠加「资料类」要求（排版、打印友好）
```

> 规则：**先选一个年级模板打底，再按科目/类型往里面加一小节**。不用背，选择即所得。

## 3. 每个模板的「特化点」速查

### A. 低年级通用（1~2 年级）

| 维度 | 特化要求 |
| --- | --- |
| 文字 | 正文 ≥ 28px，图标/图为主，文字为辅 |
| 操作 | 全程单击即可，无需输入键盘，无「计时」压力 |
| 拼音 | 生字全部注音 |
| 反馈 | 多用动画/音效式鼓励，少用文字批评 |
| 注意力 | 单屏一个任务，切换要显眼 |

### B. 中年级通用（3~4 年级）＝ 第四部分主模板

不再赘述，见《04 · 02 学生工具通用要求与模板》。

### C. 高年级通用（5~6 年级）

| 维度 | 特化要求 |
| --- | --- |
| 文字 | 正文 ≥ 18px，可接受段落文字 |
| 交互 | 可支持多步骤、输入框、较复杂逻辑 |
| 学习 | 允许错题本、难度分层、自我挑战 |
| 反馈 | 可给「解题思路讲解」，不只是对错 |

### D. 中学通用（初中/高中）

| 维度 | 特化要求 |
| --- | --- |
| 准确 | 强调概念准确、步骤严谨，宁缺毋滥 |
| 排版 | 可接受较密排版、表格、公式 |
| 自主 | 学生自测、错题收集、进度追踪 |
| 克制 | 界面可走简洁专业风，不必卡通 |

### E. 数学版（叠加在年级模板上）

- 数字/公式必须真实计算正确（AI 自己验算，禁止编题）。
- 题目难度分层（基础/提高/挑战），符合课标不超纲。
- 竖式、分数、单位换算等要按规范格式展示。
- 给结果时提供「思路」而非只有答案。

### F. 语文版（叠加在年级模板上）

- 生字/拼音必须准确，多音字要标注用法场景。
- 汉字笔画、笔顺、部首展示要按规范（如有动画逐步演示）。
- 课文/语段引用要准确，不擅自改写。

### G. 英语版（叠加在年级模板上）

- 拼写、发音必须准确；涉及音标/发音提供标准写法。
- 字号要稍大（英语字母细节多，小了看不清）。
- 中文注释策略要符合年级（低年级可全文注释，高年级逐步减少）。

### H. 练习类（叠加在年级模板上）

- 出题随机、选项打乱，避免学生背顺序。
- 判题即时、错题单独呈现并给正确思路。
- 计分鼓励为主，可设「再来一次」。

### I. 游戏类（叠加在年级模板上）

- 有明确关卡/目标，反馈频率高。
- 动画有趣但不干扰做题。
- 控制单局时长（如 5 分钟内一局），保护眼睛。
- 失败要鼓励重试，不挫伤孩子。

### J. 演示类（叠加在年级模板上）

- 适配大屏/投影（1920×1080 或自适应）。
- 关键步骤有动画或逐步展开，节奏可控（教师可暂停/上一步）。
- 字更大，坐在后排也看得清。
- 最好有「教师模式」控制按钮。

### K. 资料类（叠加在年级模板上）

- 排版清晰、留白充足，适合打印（A4）。
- 可导出/打印样式（@media print）。
- 内容分节、有标题层级，方便查找。

## 4. 组合示例：从零配一个「三年级数学口算练习」

目标：三年级数学、口算练习、练习类工具。

**第 1 步**：选年级模板 → `AGENTS.md.学生工具-通用.md`（3~4 年级主模板）。
**第 2 步**：叠加数学版 → 把 `AGENTS.md.数学版.md` 里的「数学版要求」小节追加进去。
**第 3 步**：叠加练习类 → 把 `AGENTS.md.练习类.md` 里的「练习类要求」小节追加进去。
**第 4 步**：保存为项目根目录 `AGENTS.md`，新开会话，开始干活。

> 你不需要一字不差地拼装。更省事的做法：
> 在 Reasonix 里说「把 templates 文件夹里这几个模板合并成一个 AGENTS.md 放在当前项目」，
> AI 会帮你拼好。但建议你事后自己读一遍，确认符合预期。

## 5. 模板怎么继续改造成「你自己的」

> 📌 先说明：**这里的模板都是「班规」性质**——装进某个项目根目录，只管那个项目。
> 用久了你会发现「这几点每个项目都用得上」（比如离线、中文、不收集学生信息），
> 就把那几点单独提炼成一份**全局校规**，让 AI 存进 Reasonix 的全局数据文件夹，全校（所有项目）生效。详见《04 · 安装与更新》第 0 步。

1. **加你的名字/学校要求**：加一节「## 本校要求」，写清校规、班规相关的限制。
2. **固定你的偏好**：例如「我用平板投屏，字号 24px 以上」「配色用校徽蓝」。
3. **沉淀踩过的坑**：比如「上次 AI 用了外部字体导致离线白屏，禁止任何外部资源」——写进模板，一劳永逸。
4. **版本管理**：把 templates 文件夹和你的 AGENTS.md 一起保存好，换机器直接拷。

## 6. 小结

- 选模板流程：**年级 → 科目 → 类型**，逐层叠加。
- 主模板打底，特化小节补充，5 分钟能拼出合用的 AGENTS.md。
- 模板库文件都在 `templates/` 文件夹，随时复制。
