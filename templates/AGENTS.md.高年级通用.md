# 学生工具项目（小学高年级版）

这是老师为学生制作的互动学习工具项目。
目标用户是【小学 5~6 年级】学生。这个年龄段孩子识字量足够、能理解较复杂任务，
可以接受稍多文字和更丰富的交互，但仍要避免信息过载。

## 技术栈（必须遵守）
- 做成单个 HTML 文件（HTML + CSS + JavaScript 全部内联在一个文件里），文件名 index.html。
- 必须能在本地浏览器（Chrome/Edge）里双击直接打开运行。
- 必须离线可用：不加载任何外部链接（CDN、字体、图片、API、统计代码都不行），
  不要求网络，不依赖任何安装包或服务器。
- 不要引入框架；原生 HTML/CSS/JS 即可。
- 完成后必须自己检查页面能否打开，并把打开方式告诉老师。

## 交互与界面（必须遵守）
- 文字要大（正文至少 18px），标题层级清晰。
- 按钮要大（至少 44px 高），点击区域足够。
- 可以支持：输入框、多步骤流程、难度选择、错题回顾等较丰富交互。
- 每个操作都有明确提示；反馈要即时。
- 全程简体中文，不出现英文界面文字。

## 配色（必须遵守）
- 明亮、清爽：浅色背景 + 明确的主色调。
- 避免大面积深色、荧光色；红绿不用作唯一区分手段。
- 对比度足够，投影也看得清。

## 内容与学科（必须遵守）
- 知识点必须准确，符合 5~6 年级课标，不超纲、不超前。
- 题目、选项、答案必须真实正确，不得编造。
- 提供分层难度（基础/提高/挑战）更好。
- 答错时给「解题思路」引导，不只是显示对错。

## 安全与隐私（必须遵守）
- 不收集、不上传任何学生个人信息。
- 不显示任何广告、外部链接、跳转。
- 不使用任何需要登录、注册、联网的组件。

## 交付与验收（必须遵守）
- 完成后向老师说明：文件在哪、怎么打开、覆盖哪些知识点、怎么测试的。
- 交付前自己完整玩一遍：知识正确、无卡死、无文字错误。
- 拿不准的地方先问老师，不擅自决定。

## 常用信息
- 本地预览方式：双击 index.html 或拖进浏览器即可。
- 修改需求时直接说，我会在现有文件上改，不另起炉灶。
