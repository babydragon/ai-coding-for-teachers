# 学生工具项目（小学低年级版）

这是老师为学生制作的互动学习工具项目。
目标用户是【小学 1~2 年级】学生。这个年龄段的孩子识字量小、注意力短、操作精细度有限，
所有设计必须「一看就懂、一点就会、玩得开心」。

## 技术栈（必须遵守）
- 做成单个 HTML 文件（HTML + CSS + JavaScript 全部内联在一个文件里），文件名 index.html。
- 必须能在本地浏览器（Chrome/Edge）里双击直接打开运行。
- 必须离线可用：不加载任何外部链接（CDN、字体、图片、API、统计代码都不行），
  不要求网络，不依赖任何安装包或服务器。
- 不要引入框架；原生 HTML/CSS/JS 即可。
- 完成后必须自己检查页面能否打开，并把打开方式告诉老师。

## 交互与界面（必须遵守）
- 文字要特别大：正文至少 28px，标题更大。
- 以图为主、文字为辅：用 emoji、图标、大色块表达意思。
- 操作只需要「单击」：避免拖拽、打字、计时压力、复杂的多选。
- 单屏只放一个任务，切到下一个任务时按钮要非常显眼。
- 每个操作都有声音或动画提示，孩子知道「点这里」。
- 答对给大动画+鼓励音效式反馈（鼓掌、星星），答错温柔引导，不显示任何负面字眼。
- 全程简体中文；所有汉字标注拼音（如果页面有文字说明）。

## 配色（必须遵守）
- 明亮、温暖、活泼：浅色背景 + 鲜艳点缀。
- 大色块、大对比，方便远距离辨认。
- 避免大面积深色、荧光色；红绿不用作唯一区分手段。

## 内容与学科（必须遵守）
- 知识点必须准确，符合一年级/二年级课标，不超纲、不超前。
- 题目、选项必须真实正确，不得编造。
- 单次练习量要小（每局 5 题以内），可以反复玩。

## 安全与隐私（必须遵守）
- 不收集、不上传任何学生个人信息。
- 不显示任何广告、外部链接、跳转。
- 不使用任何需要登录、注册、联网的组件。

## 交付与验收（必须遵守）
- 完成后向老师说明：文件在哪、怎么打开、覆盖哪些知识点、怎么测试的。
- 交付前自己完整玩一遍：知识正确、无卡死、无文字错误、字够大。
- 拿不准的地方先问老师，不擅自决定。

## 常用信息
- 本地预览方式：双击 index.html 或拖进浏览器即可。
- 修改需求时直接说，我会在现有文件上改，不另起炉灶。
