# 学生工具项目

这是老师为学生制作的互动学习工具项目。
目标用户是【小学 3~4 年级】学生，所有设计都必须围绕「孩子看得懂、玩得动、学得进」。

## 技术栈（必须遵守）
- 做成单个 HTML 文件（HTML + CSS + JavaScript 全部内联在一个文件里），文件名 index.html。
- 必须能在本地浏览器（Chrome/Edge）里双击直接打开运行。
- 必须离线可用：不加载任何外部链接（CDN、字体、图片、API、统计代码都不行），
  不要求网络，不依赖任何安装包或服务器。
- 不要引入框架（如 React/Vue）；原生 HTML/CSS/JS 即可，保证文件小、兼容好。
- 完成后必须自己用工具检查页面能否打开，并把打开方式告诉老师。

## 交互与界面（必须遵守）
- 目标用户是小学低中年级孩子：界面要简洁，一次只做一件事，避免信息过载。
- 文字要大（正文至少 20px）、按钮要大（至少 48px 高），适合手指点按和远距离看。
- 步骤引导要明确：每个操作都有提示，孩子知道「下一步该做什么」。
- 操作要有即时反馈：答对鼓励、答错引导，绝不只显示「错」。
- 全程简体中文，不出现英文界面文字。
- 动画要有但不能喧宾夺主，时长适中，不造成眩晕。

## 配色（必须遵守）
- 整体明亮、温暖、活泼：推荐浅色背景（米白/浅黄/浅蓝）+ 高饱和点缀色。
- 避免大面积深色、纯黑背景、刺眼的荧光色（纯红配纯绿等）。
- 对比度要足够，保证白板上投影也看得清。
- 红绿不用作唯一区分手段（色盲友好），可以配符号/文字。

## 内容与学科（必须遵守）
- 知识点必须准确，符合教育部课标对应年级的要求，不超纲、不超前。
- 数据、题目、选项必须是真实正确的，不得编造。
- 如涉及读音/发音，标注拼音或提供发音说明。
- 难度有梯度：从简单到复杂，或提供难度选择。

## 安全与隐私（必须遵守）
- 不收集、不上传任何学生个人信息（姓名、照片、输入内容都不行）。
- 不显示任何广告、外部链接、跳转。
- 不使用任何需要登录、注册、联网的组件。

## 交付与验收（必须遵守）
- 完成后向老师说明：文件在哪、怎么打开、覆盖了哪些知识点、怎么测试的。
- 交付前自己完整玩一遍，确认：知识正确、无卡死、无文字错误。
- 任何需要老师决策的地方（如某个交互方式拿不准），先问老师，不要自作主张。

## 常用信息
- 本地预览方式：双击 index.html 或拖进浏览器即可。
- 修改需求时直接说，我会在现有文件上改，不另起炉灶。
