# 学生工具项目（中学版）

这是老师为学生制作的互动学习工具项目。
目标用户是【初中/高中】学生。这个年龄段学生能处理复杂任务，重视效率与准确，
界面可以走简洁专业风，不必卡通化，但仍要避免无意义的干扰。

## 技术栈（必须遵守）
- 做成单个 HTML 文件（HTML + CSS + JavaScript 全部内联在一个文件里），文件名 index.html。
- 必须能在本地浏览器（Chrome/Edge）里双击直接打开运行。
- 必须离线可用：不加载任何外部链接（CDN、字体、图片、API、统计代码都不行），
  不要求网络，不依赖任何安装包或服务器。
- 不要引入框架；原生 HTML/CSS/JS 即可。如确需框架，必须先征得老师同意。
- 完成后必须自己检查页面能否打开，并把打开方式告诉老师。

## 交互与界面（必须遵守）
- 文字可较紧凑（正文至少 16px），但标题层级清晰。
- 可支持表格、公式、代码块、复杂输入等。
- 交互效率优先：快捷操作、键盘可用、信息密度合理。
- 反馈要即时、准确；错误提示要说明原因。
- 全程简体中文（学科专有名词可用英文缩写，如 sin、NaOH）。

## 配色（必须遵守）
- 简洁专业：低饱和主色 + 充足留白。
- 避免大面积荧光色；红绿不用作唯一区分手段。

## 内容与学科（必须遵守）
- 概念、公式、步骤必须准确严谨，宁缺毋滥。
- 题目、答案必须真实正确，AI 必须自行验算，禁止编造。
- 提供思路解析与错题回顾功能更好。
- 难度分层（基础/提高/挑战）更好。

## 安全与隐私（必须遵守）
- 不收集、不上传任何学生个人信息。
- 不显示任何广告、外部链接、跳转。
- 不使用任何需要登录、注册、联网的组件。

## 交付与验收（必须遵守）
- 完成后向老师说明：文件在哪、怎么打开、覆盖哪些知识点、怎么测试的。
- 交付前自己完整测试：知识正确、无卡死、无文字错误。
- 拿不准的地方先问老师，不擅自决定。

## 常用信息
- 本地预览方式：双击 index.html 或拖进浏览器即可。
- 修改需求时直接说，我会在现有文件上改，不另起炉灶。
